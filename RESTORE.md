# How to restore this export

This zip is a **Gmail-safe export** of the `opportunity_radar` project, meant to be
attached to an email or uploaded to GitHub.

Gmail blocks attachments (including zips) that contain files with certain
extensions (`.js`, `.mjs`, `.ps1`, `.vbs`, etc. — see
[Gmail's blocked file types](https://support.google.com/mail/answer/6590)).
To get this zip through, the few files in this project that used a blocked
extension were renamed with an extra `.txt` suffix. **Their contents were not
changed at all** — only the file name.

## Files renamed for this export

| Renamed file (in this zip)      | Restore to               |
|----------------------------------|---------------------------|
| `eslint.config.js.txt`           | `eslint.config.js`        |
| `vitest.config.js.txt`           | `vitest.config.js`        |
| `scripts/run-next.mjs.txt`       | `scripts/run-next.mjs`    |

## Option 1 — manual

Just rename each file above back to its original name (remove the trailing
`.txt`). In File Explorer: select the file, press F2, delete `.txt` from the
end of the name.

## Option 2 — one command

After extracting the zip, `cd` into the extracted folder and run **one** of
the following.

**macOS / Linux / Git Bash:**
```bash
mv eslint.config.js.txt eslint.config.js
mv vitest.config.js.txt vitest.config.js
mv scripts/run-next.mjs.txt scripts/run-next.mjs
```

**Windows PowerShell:**
```powershell
Rename-Item eslint.config.js.txt eslint.config.js
Rename-Item vitest.config.js.txt vitest.config.js
Rename-Item scripts\run-next.mjs.txt scripts\run-next.mjs
```

## What was left out of this export

This export contains only what's needed to publish the project on GitHub —
local/generated files were excluded, since they don't belong in the repo and
would only make the zip heavier:

- `node_modules/` — reinstall with `npm install` after restoring the files above.
- `.next/` — Next.js build output, regenerated by `npm run build` / `npm run dev`.
- `data/` — the local SQLite database (`opportunity_radar.db*`), which holds
  your local run data, not source code.
- `.env.local` — your local secrets/API keys. Re-create it from `.env.example`.
- `*.log` files and `tsconfig.tsbuildinfo` — local build/runtime artifacts.
- `.claude/settings.local.json` — local Claude Code tool settings.

## After restoring

```bash
npm install
cp .env.example .env.local   # then fill in your own keys
npm run dev
```
